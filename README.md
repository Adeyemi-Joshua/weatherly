# 🌤️ Weatherly

A responsive weather application built with **HTML, CSS, and JavaScript** that allows users to search for a city and view its current weather conditions and upcoming forecast.

Weatherly uses the [Open-Meteo API](https://open-meteo.com/) to retrieve real-time weather information and forecast data.

## ✨ Features

- **City Search:** Search for weather information by entering a city name.
- **Current Weather:** View the current temperature and weather conditions.
- **Weather Details:** Displays humidity and wind speed.
- **Weather Conditions:** Shows weather descriptions and corresponding icons.
- **Rain Probability:** Displays the probability of rain for the evening.
- **Three-Day Forecast:** View upcoming weather conditions and temperature forecasts for the next three days.
- **Responsive Design:** Adapts to different screen sizes, including mobile devices, tablets, and desktops.
- **Loading State:** Provides feedback while weather information is being retrieved.
- **Error Handling:** Displays appropriate messages when a city cannot be found or a request fails.
- **Keyboard Support:** Press Enter to search for a city.

## 🛠️ Technologies Used

- HTML5 – Application structure.
- CSS3 – Styling, layout, and responsive design.
- JavaScript (ES6+) – Application logic, API requests, and dynamic content.
- Open-Meteo API – Weather and forecast data.

## 🚀 Getting Started

To run Weatherly locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/weatherly.git
   ```

2. Navigate into the project folder:

   ```bash
   cd weatherly
   ```

3. Open the project in Visual Studio Code.

4. Run `index.html` using the Live Server extension.

## 🌍 API Reference

Weatherly uses the free [Open-Meteo API](https://open-meteo.com/) for:

- City geocoding and location search.
- Current weather conditions.
- Hourly precipitation probability.
- Daily temperature and weather forecasts.

No API key is required for the endpoints used in this project.
